# Anish Kumar Azad — Portfolio

A one-page animated portfolio website, built from the "Anish Kumar Azad — Portfolio" design canvas (same teal gradient, cream type, Big Shoulders Display + DM Sans).

## Run locally

It's plain HTML/CSS/JS with no build step:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

Or open `index.html` directly in a browser.

## Files

- `index.html` — all sections (Cover, Introduction, Content, 01–09 projects, Contact)
- `styles.css` — design tokens, layout, animations, responsive rules
- `script.js` — scroll reveals, letter animations, nav, progress bar, lightbox, one-video-at-a-time
- `assets/media/` — images and videos from the design

## Deploy

Works on any static host (GitHub Pages, Netlify, Vercel). For GitHub Pages: Settings → Pages → deploy from this branch, root folder.
